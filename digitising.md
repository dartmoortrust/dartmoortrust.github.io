# Dartmoor Trust — Standard Operating Procedures

**Purpose:**  
These SOPs describe the process for scanning and documenting original materials (prints, slides, glass plates, maps, books, etc.) for the Dartmoor Trust Archive.  
The Archive’s aim is to **digitise and preserve Dartmoor’s heritage** using best-practice techniques, storing master files securely and making smaller “web-friendly” versions with metadata available at [dartmoortrust.org](https://www.dartmoortrust.org).

---

## 1. Scanning Requirements

The Trust follows **National Archive Standards** where possible.

| Material Type                   | Resolution / Specs                                                                 |
|---------------------------------|------------------------------------------------------------------------------------|
| **Ordinary documents**          | 300 PPI, 24-bit sRGB                                                               |
| **Photographic prints**         | 600 PPI, 24-bit sRGB                                                               |
| **Photographic transparencies** | 4000 PPI (preferred) / 3200 PPI (acceptable), 24-bit sRGB                          |
| **Microform**                   | Equivalent to 300 PPI at original size, 24-bit sRGB (agree on max possible if not feasible) |
| **Colour space**                | 24-bit colour or 8-bit grayscale depending on source                              |
| **Storage format**              | Masters in TIFF (JP2 may be adopted later)                                        |

---

## 2. Surrogate Images
- Copies are created on request, optimised for online use rather than fixed standards.

---

## 3. Cropping
- Crop **manually** to leave a small white border around the item.  
- Avoid automatic cropping (it can cut off edges).

---

## 4. Identification & Numbering
- Number images consecutively within a collection (e.g., `XX1`, `XX2`, `XX3`) where `XX` are **unique donor/photographer initials**.
- Avoid reusing initials already assigned.

---

## 5. Front & Back Captions
- Scan **both sides** if the reverse contains information.  
- In spreadsheet:
  - Front: `ID.F` (with text)  
  - Back: `ID.B` (with text)

---

## 6. Documentation & Metadata

| Field                 | Description & Rules |
|-----------------------|---------------------|
| **Title**             | ≤ 40 characters, sentence case. Include key searchable terms. Appears on thumbnails. |
| **Detail**            | Descriptive prose with many keywords to aid searches. Use when provided; otherwise add later. |
| **Location**          | Grid reference (e.g., `SX 311 575`) if available. |
| **Direction of view** | Record in **Detail** using cardinal points (N, NE, E, SE, S, SW, W, NW). |
| **Adding metadata**   | JD enters data into records → Trustee verifies and expands as needed. |
